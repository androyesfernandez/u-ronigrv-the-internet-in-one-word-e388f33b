One word for the whole internet: **Vegas**. The entry is a single word, written to `/output/entry.txt` by a tiny dependency-free Node script. It was chosen because it compresses the internet's loudest instincts — risk, showmanship, and buying and selling — into five letters that everyone already recognises at a glance.
